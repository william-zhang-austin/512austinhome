# 512 Austin Home — Site Instructions

## What This Is
512austinhome.com — William Zhang's English-language real estate site for Austin, TX.
Built with Astro + Tailwind. Optimized for local SEO and AI/LLM discoverability (GEO/AEO).

## Read first (operations, updated 2026-11-20)
Full hub with rules, accounts, procedures, baselines and open items: `~/Desktop/EA Ashley/wiki/reference/512austinhome-site.md`. Key mechanics:
- **Commits:** author and committer `William Zhang <william@magyak.com>`, no `Co-Authored-By` line (Vercel fails the deploy otherwise). Verify with `gh api repos/william-zhang-austin/512austinhome/deployments`.
- **Builder offers:** only in `src/data/current-offers.ts` (dated, sourced, `endsOn`). Shared block `src/components/CurrentOffers.astro` renders them on incentive, builder and community pages. Never publish commission/BTSA terms; a rate only with its APR; no MLS-derived figures anywhere public.
- **Expiry:** build-time filter + daily cron `/api/rebuild/` (06:10 UTC) -> Deploy Hook `daily-offers-rebuild` (`DEPLOY_HOOK_URL`) + `data-ends-on` hide script in `BaseLayout.astro`.
- **llms.txt** is generated by `src/pages/llms.txt.ts` (not `public/`).
- **Communities:** structured entries in `src/data/communities.ts`, not blog posts; extend the `city` union for new cities.
- **After shipping:** IndexNow (`scripts/indexnow.sh`, write URLs to a file in zsh) and Search Console Request Indexing for the most important new URLs.

## Tech Stack
- Astro 6.x + MDX
- Tailwind CSS 4.x (via @tailwindcss/vite)
- @astrojs/sitemap, @astrojs/rss
- Sharp for image optimization
- Node 22+

## Content Structure
- `src/content/blog/` — Blog posts (MDX). Each gets JSON-LD Article schema automatically.
- `src/content/neighborhoods/` — Neighborhood guide pages (MDX). Each gets Place schema.
- `src/content/content.config.ts` — Collection schemas.

## SEO Rules
- Every page must have: title with target keyword, meta description, canonical URL, OG tags
- Blog posts: keyword in title, URL, H1, first sentence (Pareto SEO)
- FAQ sections on service pages use FAQPage schema — these get cited by LLMs
- SchemaMarkup component handles all JSON-LD (RealEstateAgent, LocalBusiness, Article, FAQPage, Place)
- Never remove or weaken structured data

## Content Guidelines

- Include specific neighborhood names, school districts, price data
- Use comparison format when covering multiple areas (Austin vs X)

- Cross-link between blog posts and neighborhood pages
